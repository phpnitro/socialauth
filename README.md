# phpnitro/socialauth

Connexion OAuth2 (GitHub, Facebook, Microsoft, Apple).

Fait partie de [PhpNitro](https://github.com/phpnitro/phpnitro) — un framework PHP qui compile vers de vraies apps Android natives (moteur de rendu Canvas, pas de WebView).

## Installation

```bash
composer require phpnitro/socialauth
```

## Usage

```php
use Engine\SocialAuth\OAuthProvider;
```
